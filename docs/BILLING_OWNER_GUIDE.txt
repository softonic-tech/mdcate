================================================================================
  medprep.study — BILLING SETUP GUIDE FOR WEBSITE OWNER
  JazzCash & Easypaisa (Pakistan mobile wallet payments)
================================================================================

This guide explains what YOU (the business owner) need to do so students can
pay for Pro / Ultimate plans on medprep.study using JazzCash and Easypaisa.

Your developer has already built the billing system. You only need merchant
accounts, credentials, and a few URLs registered with each provider.


--------------------------------------------------------------------------------
1. HOW BILLING WORKS ON YOUR WEBSITE (SIMPLE OVERVIEW)
--------------------------------------------------------------------------------

  • New students get a 7-day FREE TRIAL when they sign up.
  • After the trial ends, they see an upgrade popup and must pay to continue.
  • They choose a plan (Pro or Ultimate) on the Billing page.
  • They pay using JazzCash OR Easypaisa (mobile wallet only — no cards on site).
  • When payment succeeds, their plan activates automatically.
  • You manage prices and features from the Admin Panel → Pricing Plans.
  • You can view all payments in Admin Panel → Payments.

  Student flow:
    Landing page (#pricing) → Sign up → 7-day trial → Billing page → Pay → Active plan

  Admin pages:
    Pricing Plans:  /admin/pricing-plans
    Payments:       /admin/payments

3. JAZZCASH MERCHANT SETUP
--------------------------------------------------------------------------------

STEP A — Register for sandbox (testing)
  1. Go to: https://sandbox.jazzcash.com.pk
  2. Sign up for a free sandbox merchant account.
  3. Complete merchant registration and wait for sandbox credentials.

STEP B — Get these credentials from JazzCash
  After approval, JazzCash will give you:

    • Merchant ID          (pp_MerchantID)
    • Merchant Password    (pp_Password)
    • Integrity Salt       (used for secure hash — keep secret)
    • Sub-Merchant ID      (optional — only if they provide one)

STEP C — Register callback URL with JazzCash
  Tell JazzCash support / portal to whitelist this URL:

    SANDBOX (testing):
      Your backend URL + /api/v1/billing/payments/jazzcash/callback

    Example (replace with your real API domain):
      https://api.medprep.study/api/v1/billing/payments/jazzcash/callback

  Also register your website return URL prefix (JazzCash requires this):
    https://medprep.study/dashboard/billing/callback

STEP D — Give credentials to your developer (or add to backend .env)
  Add these lines to backend/.env:

    JAZZCASH_MERCHANT_ID=your_merchant_id
    JAZZCASH_PASSWORD=your_password
    JAZZCASH_INTEGRITY_SALT=your_integrity_salt
    JAZZCASH_SUB_MERCHANT_ID=          (leave empty if not provided)

  For sandbox testing only, you may also set:
    JAZZCASH_CHECKOUT_URL=https://sandbox.jazzcash.com.pk/CustomerPortal/transactionmanagement/merchantform/

STEP E — Go live (production)
  1. Apply for a LIVE JazzCash merchant account (contact JazzCash business team).
  2. Replace sandbox credentials with production credentials in .env.
  3. Remove or update JAZZCASH_CHECKOUT_URL to production URL (developer handles this).
  4. Re-register production callback URL with JazzCash.

  JazzCash business contact (general):
    Website: https://www.jazzcash.com.pk
    Merchant / business inquiries via JazzCash official channels or your bank relationship manager.


--------------------------------------------------------------------------------
4. EASYPAISA MERCHANT SETUP
--------------------------------------------------------------------------------

STEP A — Register for sandbox (testing)
  1. Contact Easypaisa merchant onboarding OR use their merchant portal if available.
  2. Request an Easypay / online payment merchant account for your website.
  3. Ask specifically for: "Hosted checkout / Easypay integration" (website redirect).

  Sandbox checkout base URL (for reference):
    https://easypaystg.easypaisa.com.pk/easypay/Index.jsf

STEP B — Get these credentials from Easypaisa
  After approval, Easypaisa will give you:

    • Store ID             (storeId)
    • Hash Key             (16-character secret key for encryption — keep secret)

  IMPORTANT: The Hash Key must be exactly 16 bytes/characters as per Easypaisa docs.

STEP C — Register callback URL with Easypaisa
  Tell Easypaisa to whitelist this postback URL:

    SANDBOX / LIVE:
      Your backend URL + /api/v1/billing/payments/easypaisa/callback

    Example:
      https://api.medprep.study/api/v1/billing/payments/easypaisa/callback

  Requirements Easypaisa usually enforces:
    • URL must be HTTPS in production (not http)
    • URL must be publicly reachable (not localhost)

STEP D — Give credentials to your developer (or add to backend .env)
  Add these lines to backend/.env:

    EASYPAISA_STORE_ID=your_store_id
    EASYPAISA_HASH_KEY=your_16_char_hash_key

  For sandbox testing only:
    EASYPAISA_CHECKOUT_URL=https://easypaystg.easypaisa.com.pk/easypay/Index.jsf

STEP E — Go live (production)
  1. Complete Easypaisa merchant KYC / business verification.
  2. Replace sandbox Store ID and Hash Key with live credentials.
  3. Update checkout URL to production:
       https://easypay.easypaisa.com.pk/easypay/Index.jsf
  4. Confirm live postback URL is registered with Easypaisa.

  Easypaisa business contact (general):
    Website: https://easypaisa.com.pk
    Merchant services — contact via Easypaisa business / merchant support.


--------------------------------------------------------------------------------
5. SERVER / WEBSITE URLS YOU MUST PROVIDE
--------------------------------------------------------------------------------

Give your developer (or hosting provider) these production URLs:

  FRONTEND_URL=https://your-website.com
  BACKEND_URL=https://your-api-domain.com

  Examples:
    FRONTEND_URL=https://medprep.study
    BACKEND_URL=https://api.medprep.study

  Why BACKEND_URL matters:
    Easypaisa sends payment confirmation to your backend API.
    JazzCash also posts payment results to your backend callback.

  Both must use HTTPS in production.

7. MANAGING PLANS & PRICES (ADMIN PANEL)
--------------------------------------------------------------------------------

  Login to admin panel → Pricing Plans

  You can edit for each plan:
    • Name (e.g. Pro, Ultimate)
    • Price in PKR
    • Duration in days (e.g. 90 = 3 months, 180 = 6 months)
    • Period label shown on landing page (e.g. "/ 3 months")
    • Feature list (one feature per line)
    • "Popular" badge
    • Active / hidden on website

  Changes appear on:
    • Landing page pricing section
    • Dashboard billing page

  Default plans (seeded on first server start):
    Free     — PKR 0
    Pro      — PKR 1,499 / 90 days
    Ultimate — PKR 2,999 / 180 days


--------------------------------------------------------------------------------
8. VIEWING & MANAGING PAYMENTS (ADMIN PANEL)
--------------------------------------------------------------------------------

  Admin Panel → Payments

  You will see:
    • Student email
    • Plan purchased
    • Amount (PKR)
    • Provider (jazzcash / easypaisa / manual)
    • Status (pending / completed / failed)
    • Transaction reference
    • Date

  Manual approve:
    If a student paid but status stuck on "pending", click Approve to activate
    their plan manually (use only after verifying payment with JazzCash/Easypaisa).

10. COMMON ISSUES & WHO TO CONTACT
--------------------------------------------------------------------------------

  PROBLEM: "Request Rejected" on Easypaisa page
  CAUSE:   Wrong Store ID, Hash Key, or postback URL not whitelisted
  FIX:     Re-check credentials with Easypaisa; confirm callback URL registered

  PROBLEM: JazzCash shows "Invalid hash" or payment fails immediately
  CAUSE:   Wrong Integrity Salt or Merchant Password
  FIX:     Re-copy credentials from JazzCash portal exactly (no extra spaces)

  PROBLEM: Payment succeeds but plan not activated
  CAUSE:   Callback URL not reachable or blocked by firewall
  FIX:     Ensure BACKEND_URL is correct, HTTPS works, and URL is whitelisted

  PROBLEM: Student stuck after trial, popup keeps showing
  CAUSE:   Payment not completed or failed
  FIX:     Check Admin → Payments; manually approve if payment verified

  PROBLEM: localhost testing fails for Easypaisa callback
  CAUSE:   Easypaisa requires public HTTPS URL for postback
  FIX:     Use ngrok or deploy to staging server for gateway testing

  WHO TO CONTACT:
    JazzCash merchant support  → for credential / callback URL issues
    Easypaisa merchant support → for Store ID / Hash Key / postback issues
    Your developer            → for website / server / .env configuration


--------------------------------------------------------------------------------
11. FEES, SETTLEMENTS & COMPLIANCE (OWNER RESPONSIBILITY)
--------------------------------------------------------------------------------

  • JazzCash and Easypaisa charge merchant transaction fees (confirm rates when signing up).
  • Settlements are usually transferred to your registered bank account on a schedule
    defined in your merchant agreement (often T+1 to T+3 business days).
  • Keep records of all transactions for tax / accounting purposes.
  • Display clear pricing and refund policy on your website (recommended).
  • Ensure your terms mention subscription duration and auto-expiry after plan ends.
